# AI Orchestrator — iam.aiorchestrator.com.au

Modernised recreation of the AI Orchestrator personal profile site, on the original colour
scheme (warm white, ink, soft pink, lavender, pink-to-lavender gradient).

- `index.html` — the whole site (single self-contained file, Google Fonts via CDN)
- `favicon.svg` — monogram mark

## Deploy (static site, no build step)

- **Netlify:** New site from Git -> pick this repo -> Build command: (none) -> Publish directory: `/`
- **Vercel:** Import repo -> Framework preset: Other -> no build -> Output: root

Then point `iam.aiorchestrator.com.au` at the site in the host's domain settings.
